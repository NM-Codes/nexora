# Nexora — Better talent. Faster.

Nexora is a lightweight Applicant Tracking System for managing job openings, candidate profiles, and recruitment pipelines.

## Product direction

The interface is being designed from the provided Nexora references: a calm, compact recruiting workspace with a left navigation rail, candidate Kanban, job management, candidate profiles, customer administration, and a shared sign-in flow. The brand palette is navy `#1A2433`, slate `#7C8CA3`, mist `#E8EEF5`, and cloud `#F7F9FC`.

## Working agreement

- Work one sprint at a time, with the user choosing the frontend scope and design details.
- Build the frontend first. Do not implement the backend until the user says the frontend is ready.
- Keep the product architecture and data contracts in [docs/architecture.md](docs/architecture.md).

## Run locally

```bash
npm install
npm run dev
```

The frontend scaffold uses React, TypeScript, and Vite. The backend remains deferred until the frontend is ready. Build the interface one sprint at a time, with frontend scope and design led by the user.
